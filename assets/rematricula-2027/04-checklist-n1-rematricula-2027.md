# Checklist N1 — Rematrícula 2027

**Status:** Rascunho  
**Uso:** Atendimento humano e base futura do Roger após validação

## Antes de orientar

- [ ] Confirmar unidade.
- [ ] Confirmar aluno/série.
- [ ] Confirmar se quem acessa é Responsável Financeiro ou Responsável Acadêmico.
- [ ] Identificar etapa do Portal.
- [ ] Identificar mensagem de erro ou comportamento inesperado.
- [ ] Confirmar se há pendência financeira/cadastral/acadêmica/contratual.
- [ ] Solicitar evidência apenas se necessário, sem dados sensíveis.

## Classificação do problema

### Acesso/Login

- [ ] E-mail do RF confere com o cadastro?
- [ ] Responsável tentou “Esqueceu a senha?”
- [ ] RA está tentando acessar no lugar do RF?
- [ ] RF e RA usam mesmo e-mail sendo pessoas diferentes?

### Início da rematrícula

- [ ] Rematrícula aparece no menu?
- [ ] Aluno aparece para o responsável?
- [ ] Existe bloqueio por inadimplência?
- [ ] Existe bloqueio acadêmico/cadastral?

### Cadastro

- [ ] Subetapas foram salvas?
- [ ] Há campo obrigatório em branco?
- [ ] Há pedido de alteração de RF?
- [ ] Pessoas autorizadas foram localizadas/cadastradas por CPF?

### Pré-contrato / acadêmico

- [ ] Série está correta?
- [ ] Turno está correto?
- [ ] Há pedido de troca de turno?
- [ ] Há bolsa/aditivo divergente?

### Serviços / bilíngue

- [ ] Serviço aparece corretamente?
- [ ] Serviço é obrigatório ou opcional? **Pendente regra 2027**
- [ ] Valores e condições conferem? **Pendente regra 2027**
- [ ] Há impacto no contrato? **Pendente regra 2027**

### Pagamento / contrato

- [ ] Serviços foram confirmados?
- [ ] Meio de pagamento aparece?
- [ ] Contrato/minuta aparece?
- [ ] Assinatura digital foi concluída?
- [ ] Pagamento foi aprovado/processado?
- [ ] Contrato final aparece no Portal?

## Quando escalar

- [ ] Alteração de Responsável Financeiro.
- [ ] Valor, bolsa, desconto ou cobrança divergente.
- [ ] Inadimplência acima da regra de liberação definida.
- [ ] Série/turma/turno divergente.
- [ ] Contrato não aparece ou está incorreto.
- [ ] Falha sistêmica no Portal.
- [ ] Questões jurídicas: guarda, imagem, deficiência, nome social, rescisão, informações financeiras a terceiros.

- [ ] Serviços bilíngues.
- [ ] Fluxo oficial de chamados.
- [ ] Canais de suporte e horários.
